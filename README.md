🍽️ Swaad Restaurant – Voice-Based Ordering System
About the Project
Swaad Restaurant is a multilingual, voice-based restaurant ordering system developed using Python as part of a team project during a one-month Speech Technology internship.

The application allows customers to interact with the system using voice commands instead of manually entering their orders.

Features
Multilingual support: English, Hindi, and Assamese.
Voice-based interaction with customers.
Language selection at the beginning of the conversation.
Accepts food orders through voice commands.
Provides voice-based responses.
Confirms customer orders before completing the ordering process.
Technologies Used
Python
SpeechRecognition
Edge TTS
Jupyter Notebook
How It Works
The application welcomes the customer.
It asks the customer to select their preferred language.
The conversation continues through voice interaction.
The customer places food orders using voice commands.
The system processes and confirms the order.
Project Type
Team Project – Developed as the final project during a Speech Technology internship.

Learning Outcomes
Understanding of speech recognition and audio processing.
Practical exposure to Speech-to-Text (STT) and Text-to-Speech (TTS).
Experience working with Python speech-processing libraries.
Collaborative project development and implementation.
